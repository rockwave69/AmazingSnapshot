# Amazing Snapshot (III/VC/SA)
A remake of the legendary AmazingScreenshot (https://gtaforums.com/topic/543523-amazing-screenshot/) with classic controls based on the Plugin SDK, featuring enhanced functionality while maintaining its lightweight design

# Controls

- Alt + V — enable or disable screenshot mode.
- V — switching between player and free mode.
- W, A, S, D / arrow keys — move the camera.
- Space / Page Up — move the camera up.
- C / Page Down — move the camera down.
- Mouse — rotate the camera.
- LMB — lock horizontal rotation.
- RMB — lock vertical rotation.
- Shift — speed up camera movement.
- Ctrl — slow down camera movement.
- "[ ]"— reduce or increase the camera zoom.
- P — reset the zoom.
- F12 — take a screenshot via the game system.
- F1 — show or hide the hint menu.
- F2 — enable or disable visual effect recording.
- Tab — switch to widescreen mode.
- "- / +" — reduce or increase the in‑game hour.
- 1–0 — select the weather with an ID from 0 to 9.
- Shift + 1–9 — select the weather with an ID from 10 to 18.
- Ctrl + 1–4 — select the weather with an ID from 19 to 22.
- Esc — exit screenshot mode.
